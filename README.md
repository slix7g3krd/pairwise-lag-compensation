# pairwise-lag-compensation

高延迟玩家打移动靶，命中判定落在靶子身后半米，低延迟玩家却打不中静止目标：服务器回溯按固定 ping 补偿，没有用实际 tick 和插值时间；命中盒历史只存最近 20 tick，高延迟超过窗口后查到空；回溯位置用线性插值，急停转向的角色被插到墙里；客户端上报的射击时间没做时钟同步，服务器按包到达时间回算；丢包重传的射击被当成新射击，同一发子弹判定两次；延迟补偿只回退角色，不回退电梯和移动平台，靶子相对位置错；近战判定在客户端做，服务器只复核伤害，穿墙刀照样生效；高延迟玩家被优先照顾，低延迟玩家射击被回退到过去位置；命中盒用绑定姿势，动作中头部和武器判定框偏移；服务器 tick 率低于客户端，回溯到两个 tick 之间没有采样；反作弊把回溯命中标记为异常，正常高 ping 玩家被踢；浮点原点重置后历史坐标没换算，远处命中盒整体偏移；投射物和 hitscan 用两套时钟，爆炸范围和命中点对不上。gameplay/lag_compensation.py 是核心，tests/test_lag_compensation.py 15个红。要修的是：tick 加插值；环形窗口扩容；插值防护；时钟同步；重传去重；移动平台；近战服务器判定；公平回退；蒙皮命中盒；子 tick 采样；反作弊白名单；原点换算；投射物时钟。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
